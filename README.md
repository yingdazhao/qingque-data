# 青雀古籍 · 文本数据

青雀古籍是一个古籍文本开放项目，重点整理唐代及以前的汉语文献。

本人在学习与研究中，曾为寻找可靠且便于使用的古籍文本耗费大量时间与精力。青雀古籍正是为解决这一问题而创立：我们希望减少每个人重复寻找和整理文本的负担，让高质量古籍文本成为人人都能平等获取和使用的公共资源。

项目已发布的数据可免费获取；在适用许可范围内，允许复制、修改和商业使用，以署名和相同方式共享支持成果的持续开放。数据按整理进度逐步发布，并持续完善。

首批试点开放《龙龛手镜》和《新修玉篇》，路径保持为 `data/古辞书综合/`。

项目主站：[青雀古籍](https://hanyuyuwenxue.cn/)。主站提供配套的文本检索查询和古籍原书影像查看功能，便于阅读、检索及结合书影核对录文。本仓库保存逐步开放的结构化文本及校订历史。

本数据经过持续分行、条目结构化、批量校对与逐步完善，保留录文、版本定位信息及必要的校勘标记。两份数据当前均为**粗校**，仍可能存在错字、缺漏及字段标注错误；用于研究、引用或出版时，请结合所据版本核对。
