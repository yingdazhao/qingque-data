# 数据与来源说明

配套的文本检索查询和古籍原书影像查看功能位于[青雀古籍主站](https://hanyuyuwenxue.cn/)。使用数据时，可结合主站提供的相应书影核对文字和版本定位。

六份 CSV 均以 UTF-8 保存。保留字形、原有标点、校勘标记及结构行；空字头不自动表示无效记录，CSV记录数不等于字数或字条数。发布时不进行正文规范化、简繁转换或异体合并。

## 来源及质量

《说文解字》来自施谢捷先生制作并公开的精校《说文解字》DOCX 文本。本项目将其结构化，并配齐大徐本和两种小徐本的页码信息：大徐本为国家图书馆藏宋本（额勒布本），小徐本分别为述古堂影抄本、祁寯藻本（初印）。

《篆隶万象名义》《新撰字镜》来自 [HDIC：平安时代汉字字书综合数据库](https://github.com/shikeda/HDIC) 的开放文本。HDIC 编纂委员会由池田证寿（池田証壽）主持；《篆隶万象名义》文本负责人为李媛，《新撰字镜》文本录入与校对负责人为李媛、影像数据库设计与实现负责人为刘冠伟（劉冠偉）。感谢原编纂团队的录入、校对与开放工作。

本项目在 HDIC 数据基础上更正了部分文字讹误，统一 ID，并配齐重要版本的页码。上游数据及其本项目改编成果依 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 共享；本项目的修改不表示 HDIC 团队对其认可或背书。HDIC 目前公开的相应文本入口为《篆隶万象名义》KTB.tsv、《新撰字镜》TSJ_entries.tsv / TSJ_definitions.tsv；本项目最初取得数据的上游提交版本尚未登记，不将当前上游版本冒充当时来源版本。

《龙龛手镜》《新修玉篇》的初始录文取自网络，具体来源未能追溯；后续持续进行分行、结构化、校对与完善。所据底本按项目现有登记说明，不代表每条已核对全部版本。

《原本玉篇》汇总现存残卷及相关抄本、引文中的条目，“来源”列保留各条材料来源；“苏芃”“行”“续四库”“姚永铭”为现有研究及版本定位列，空值保持原状。

## 字段

《说文解字》：“说文ID”标识条目，“名义ID”为跨书关联；保留字头、异体、注文、小徐对校、大徐按语、大徐反切及部首、卷序等字段。版本定位列“大徐（国图）”“小徐（述古堂）”“小徐（祁寯藻）”分别对应上文所列版本。

《篆隶万象名义》：公开文件沿用简称 `万象名义.csv`。“名义ID”标识条目，“宋玉ID”为跨书关联；保留字头、注文、备注、类型及部首、卷序等字段。“高山寺（崇文院）”“高山寺（资料丛书）”“吕浩”为现有版本及整理本定位列，按具体版本核对。

《新撰字镜》：“字镜ID”标识条目，“名义ID”“宋玉ID”为跨书关联；保留字头、注文、备注、来源、部首、卷序及“SJ2分组码”等字段。“张磊”“天治本”为整理本及版本定位列。

跨书关联 ID 可能指向尚未公开的其他材料；保留其原值，不表示对应材料已经发布。

《龙龛手镜》：字头、注文为录文；四声、部首、部首序、卷序为结构信息。部首序保留各卷局部编号。高丽本、藤本幸夫、续古逸、宋本（国图）、宋本（台北故宫）为相应版本的定位字段，其数字需结合具体版本解释。

《新修玉篇》：保留校对状态、字头、异体、注文、笔画（不准）、来源（不准）、部首、部首序、部首说明、卷序、篇、金刻本等实际字段。“笔画（不准）”“来源（不准）”明确保留待核性质，不能当作已核实的笔画或文献来源判断。“校对状态”标为 `1`，表示该条记录已经人工审核；该列不取代全文件的粗校质量登记。金刻本为版本定位字段。

《原本玉篇》：“原玉ID”标识条目，“名义ID”为跨书关联；字头、注文为录文，卷序、部首、部首序为结构信息。来源及研究、版本定位字段按各条原值保留。

2026-10-30 更新：两书均保留“校对状态”“校勘记”及新增定位字段。《新修玉篇》另有“笔画（推导）”，以保留原笔画标记为主，确定的部首开头无标记段写作“〔無標記〕”，并非逐字核定的笔画数。

两书的“行序”“行内字序”分别记录原书本页自右向左的行次及该行自上向下的实体大字次序，未知留空；《新修玉篇》对应金刻本，《龙龛手镜》对应高丽本。两轴独立，置信度列分别对应各轴；数字分值及“高”“中”“低”等文字等级不代表校准概率，也不表示全部经过逐条图核。多位置使用 JSON 数组，下标保持实体配对，未知位置用 `null`，不得分别排序或去重。

“推导页内字序”由当前 CSV 顺序计算，不等于原书实体大字累计数。《新修玉篇》连续同头音义共序，多字合收计为一个字条组；《龙龛手镜》多字字头按字头单元数累计，无数字高丽本页码时留空。《新修玉篇》旧“索引”“索引置信度”为冻结的历史兼容列，当前位置以分轴字段为准。上述字段均仍可能存在待核问题，不能据填充与否提升数据质量等级。

部首标题和统计说明可能独立占行。缺文标记、空值及“龍龕餘部”“龍龕雜部”等原有说明保留，不擅自补全或删除。

## 校勘符号

以下解释来自工作项目的古辞书综合规范，用于本仓库发布的古辞书录文：

| 写法 | 基本含义 |
| --- | --- |
| `A〈B〉` | 底本 A 为讹字，改为 B |
| `［B］` | 底本脱文，补入 B |
| `≮A≯` | 底本衍文，删除 A |
| 带圈阿拉伯数字 | 校勘记角标，不属于正文 |

乙正可由删除与补入组合表示。普通圆括号、书名号、引号及 ASCII 括号不自动按上述规则解释。多字校改、嵌套及未闭合等有歧义标记须保留待核，不能按括内字数猜测替换范围；上述规则也不用于无差别清洗结构或说明字段。
