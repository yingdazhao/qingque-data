# 数据与来源说明

配套的文本检索查询和古籍原书影像查看功能位于[青雀古籍主站](https://hanyuyuwenxue.cn/)。使用数据时，可结合主站提供的相应书影核对文字和版本定位。

两份 CSV 均以 UTF-8 保存。保留字形、原有标点、校勘标记及结构行；空字头不自动表示无效记录，CSV记录数不等于字数或字条数。发布时不进行正文规范化、简繁转换或异体合并。

初始录文取自网络，具体来源未能追溯；后续持续进行分行、结构化、校对与完善。所据底本按项目现有登记说明，不代表每条已核对全部版本。

## 字段

《龙龛手镜》：字头、注文为录文；四声、部首、部首序、卷序为结构信息。部首序保留各卷局部编号。高丽本、藤本幸夫、续古逸、宋本（国图）、宋本（台北故宫）为相应版本的定位字段，其数字需结合具体版本解释。

《新修玉篇》：保留校对状态、字头、异体、注文、笔画（不准）、来源（不准）、部首、部首序、部首说明、卷序、篇、金刻本等实际字段。“笔画（不准）”“来源（不准）”明确保留待核性质，不能当作已核实的笔画或文献来源判断。校对状态列不取代全文件的粗校质量登记。金刻本为版本定位字段。

部首标题和统计说明可能独立占行。缺文标记、空值及“龍龕餘部”“龍龕雜部”等原有说明保留，不擅自补全或删除。

## 校勘符号

以下解释来自工作项目的古辞书综合规范，仅用于本次发布的两份古辞书录文：

| 写法 | 基本含义 |
| --- | --- |
| `A〈B〉` | 底本 A 为讹字，改为 B |
| `［B］` | 底本脱文，补入 B |
| `≮A≯` | 底本衍文，删除 A |
| 带圈阿拉伯数字 | 校勘记角标，不属于正文 |

乙正可由删除与补入组合表示。普通圆括号、书名号、引号及 ASCII 括号不自动按上述规则解释。多字校改、嵌套及未闭合等有歧义标记须保留待核，不能按括内字数猜测替换范围；上述规则也不用于无差别清洗结构或说明字段。
