# 校订历史说明

本仓库按发布批次，从青雀古籍本地工作仓库筛选导入已开放书籍的 Git 历史，包含更名前的相关文件路径。历史导入时将路径统一到当前 `data/古辞书综合/` 分类，因此旧目录更名过程不完整呈现。首批为《龙龛手镜》《新修玉篇》，第二批为《说文解字》《篆隶万象名义》《新撰字镜》，第三批为《原本玉篇》。

历史作者及提交者均为同一维护者使用的署名，现统一为 YingdaZhao，邮箱使用 GitHub 隐私邮箱。保留提交说明及作者、提交时间；筛选后提交哈希发生变化，仅涉及未发布文件的提交被排除。原提交说明可能涉及同次校订的其他书籍，这不表示这些书的数据已随本仓库发布。

导入历史中的旧版本可能存在后来已修正的错误；最新数据及质量说明不追溯赋予旧版本。Git 首次入库以前的整理工作未包含在这些记录中。

[提交对应表](历史提交对应.csv)记录保留下来的原提交与发布提交对应关系，不包含被排除提交的清单。同一原提交涉及不同发布批次时，可以对应多个按不同范围筛选的公开提交。新批次通过合并导入，保留已经发布的提交编号；后续维护将在公开仓库继续记录发布的校订变化。

2026-10-30：同步工作项目中《新修玉篇》《龙龛手镜》的当前 CSV，包含录文、校勘及结构整理、分轴定位与推导字段更新。《新修玉篇》为 68,813 条记录，《龙龛手镜》为 23,703 条记录（均不含表头，不等于字数或字条数）。本次以一次发布提交记录相对上一公开版本的累计变化，未重新筛选或改写已公开历史；两书质量登记仍为粗校。字段的用途与待核性质见[数据说明](数据说明.md)。

2026-10-31：第三批开放《原本玉篇》，从工作项目筛选并合并该书当前及旧路径的 Git 历史，同步当前 CSV 与公开说明。当前文件为 2,187 条记录（不含表头，不等于字数或字条数），质量登记为出版；历史版本不追溯赋予这一质量等级。
